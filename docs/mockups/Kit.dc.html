Kit: what plugins can now describe

Every piece below is a node in eave-api's ui vocabulary, drawn by the host in kit.rs. Plugins pick nodes and tones; the host owns sizes, colors and motion. Popovers share one width (320), so rows can push content to the right edge, lists can scroll past six rows, and sliders can fill.
